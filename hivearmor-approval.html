Navigation Design Decisions
Section grouping: Workflow-first, not technology-first. "Security Ops" before "Detection" before "Dashboards" — mirrors analyst mental model from triage → investigation → visibility.
Active indicator: 2px left border in var(--ha-primary) + teal icon + teal text + 10% teal background. Three visual signals — not color-only.
Badge logic: Analyst Queue shows critical-red count badge (actionable items). Incidents shows muted-gray count (informational). Dashboard Studio shows purple "NEW" — intelligence accent, not severity.
Collapsed state: Icon only. No wordmark rotated vertically (anti-pattern). Critical badge dot preserved on queue icon. Tooltips on hover (not shown here).
Administration: Always at bottom. Requires ROLE_ADMIN. Visual separator via spacer before it.
Section labels: 9px uppercase, letter-spaced, var(--ha-muted). These are structural — not clickable. No icons on section labels.
