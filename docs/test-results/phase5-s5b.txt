## Feature Summary
- Liquibase table: hive_saved_query (id, user_login, query_name, query_text, index_pattern, time_range JSONB, filters JSONB, is_shared, created_at, updated_at)
- Indexes: idx_hive_saved_query_user_login, idx_hive_saved_query_is_shared
- Entity: UtmSavedQuery with @EntityListeners(AuditingEntityListener.class)
- Repository: findByUserLoginOrIsSharedTrueOrderByCreatedAtDesc() for GET list
- REST endpoints:
    GET    /api/ha-saved-queries  — own + shared; ANALYST/USER/SOC_MANAGER/ADMIN/READ_ONLY
    POST   /api/ha-saved-queries  — create; ANALYST/USER/SOC_MANAGER/ADMIN (READ_ONLY → 403)
    PUT    /api/ha-saved-queries/{id} — owner or ADMIN only; otherwise → 403
    DELETE /api/ha-saved-queries/{id} — owner or ADMIN only; otherwise → 403
- Frontend service: savedQueryService (list/create/update/delete) using @/lib/api
- Component migration: log-saved-queries.tsx now calls savedQueryService.list/create/update/delete
- localStorage migration banner: appears when backend is empty AND localStorage has 'savedQueries' key
  - "Import N saved queries from this browser?" banner with Import button
  - Import → POST each item → remove localStorage key → refetch from backend
  - Dismiss → hides banner but DOES NOT delete localStorage data
